# Personal Portfolio

## Setup Instructions

1. **Edit the content**: Update `index.html` with your information
2. **Create GitHub repository**: 
   - Go to GitHub and create a new repository named `yourusername.github.io`
3. **Push your code**:
   ```bash
   cd ~/portfolio
   git init
   git add .
   git commit -m "Initial portfolio"
   git branch -M main
   git remote add origin https://github.com/yourusername/yourusername.github.io.git
   git push -u origin main
   ```
4. **Enable GitHub Pages**:
   - Go to repository Settings → Pages
   - Source: Deploy from branch `main`, folder `/ (root)`
   - Save

Your site will be live at `https://yourusername.github.io` in a few minutes.

## Customization

- Replace "Your Name" and contact details in `index.html`
- Add your experience, projects, and skills
- Modify colors in `style.css` to match your preference
